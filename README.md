# breaking-the-silence
A mental health awareness website promoting emotional well-being and access to support.
https://mental-health-awaren-n1js.bolt.host
## Features
- Mental health awareness and educational content
- Self-care and wellness activities
- Mental well-being survey
- Supportive resources

## Live Website
[Visit Breaking the Silence](https://mental-health-awaren-n1js.bolt.host)

## Technologies Used
- TypeScript
- React
- Vite
- CSS

## Project Purpose
This project aims to promote mental health awareness and provide accessible educational information and self-care resources.

## Disclaimer
This website is for educational and awareness purposes and is not a substitute for professional mental health care.
